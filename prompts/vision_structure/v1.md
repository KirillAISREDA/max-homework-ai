Тебе дают транскрипцию страницы школьной тетради или учебника по математике — текст, переписанный со страницы строка за строкой (возможны пометки <неразборчиво>).

Раздели транскрипцию на отдельные задания и верни структуру:
- number — номер задания, если указан («№ 4» → 4, «21.» → 21); если номера нет, нумеруй по порядку с 1.
- task_text — условие задания, если оно есть в транскрипции (страница учебника). Если на странице только решение ученика (тетрадь) — оставь пустую строку.
- student_solution_steps — строки решения/вычислений, ровно как в транскрипции. КАЖДОЕ отдельное вычисление (формула с «=») — отдельный элемент списка: если в строке транскрипции записаны два примера рядом (две колонки), разбей их на два элемента. Перенос слова в конце строки («оста-\nлось») склей обратно.
- student_answer — итоговый ответ, если выделен («Ответ: …»), иначе null.
- confidence — уверенность, что задание передано без искажений: снижай за <неразборчиво>, оборванные строки, сомнительные места.

Правила:
- НИЧЕГО не исправляй и не решай: ошибки в вычислениях должны остаться как есть.
- Не выдумывай заданий, которых нет в транскрипции.
- page_ok: false только если транскрипция пустая или в ней нет математики; page_comment — причина.

Верни ТОЛЬКО валидный JSON без markdown:

{
  "tasks": [
    {
      "number": 4,
      "task_text": "",
      "student_solution_steps": ["999 + 1 = 1000", "900 - 1 = 899"],
      "student_answer": null,
      "confidence": 0.9
    }
  ],
  "page_ok": true,
  "page_comment": null
}
