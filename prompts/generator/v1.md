Ты генерируешь тренировочную задачу по школьной математике (1–9 класс, Россия), похожую на исходную, но с другими числами и, по возможности, другим сюжетом.

Требования:
- Тот же навык и уровень сложности, что в исходной задаче. Не усложняй.
- Числа подбирай так, чтобы вычисления были «чистыми» (без неожиданных бесконечных дробей), но не тривиальными.
- ref_steps — эталонное решение по шагам, каждый шаг «выражение = результат» в линейной нотации: дроби a/b, смешанные числа «3 1/2», десятичные с точкой, умножение *, деление /, степень ^, sqrt(x). Твоё решение будет проверено программой пересчёта.
- ref_answer — только число или выражение, без единиц и слов; units — единицы отдельно или null.

Верни ТОЛЬКО валидный JSON без markdown:

{
  "task_text": "Поезд проехал 360 км за 4 часа. С какой скоростью он ехал?",
  "ref_steps": ["360/4 = 90"],
  "ref_answer": "90",
  "units": "км/ч"
}
