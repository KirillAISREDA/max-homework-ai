# Прогон стенда 28.09.2026: модели шлюза организаторов на эталонной разметке

10 кейсов из открытого датасета `ai-forever/school_notebooks_RU` (по одной странице, 226 строк эталона),
9 конфигураций. Фото тестеров в сторонние модели не отправлялись — поэтому кейсы `hw*` и `live*` в прогон
не вошли. Страницы трудные: 5–7 класс, столбики, дроби, уравнения, разворот боком.

Распознавание — модель конфигурации; разбор страницы и эталон — `gigachat-2-max` через шлюз (в базовой
конфигурации — GigaChat API напрямую). Промпт распознавания `vision/v3` один для всех моделей, он писался под
GigaChat.

## Вывод коротко

1. **Любая модель шлюза читает тетради лучше GigaChat-2-Max.** Доля ненайденных заданий падает с 67 % до
   13–53 %, символьные ошибки — с 74 % до 44–54 %, строк «точно как в тетради» — с 8 % до 15–30 %.
2. **Лучшие по итогу проверки — Gemini 3.1 Pro и Claude Opus 4.8**: не найдено 2 задания из 15. У Gemini 3.1
   Pro больше верных вердиктов (7 из 13) и меньше ложных «ошибок» (2 из 11), у Claude Opus 4.8 точнее строки
   (30 %, CER 44 %).
3. **Gemini 2.5 Flash — лучшее соотношение цены и качества**: 0,21 ₽ и 3 с на страницу, CER 45 %, но задание
   не найдено в 4 случаях из 15.
4. **GPT-5.5 и Gemini 2.5 Pro не годятся по времени и цене**: 40 и 69 с на страницу (медиана), до 144 и 274 с;
   17 и 12 ₽ за вызов. Gemini 2.5 Pro не досчитана: запросы обрывались по таймауту 90 с.
5. **Текстовые шаги через шлюз** (`gw-gigachat-text`) дают то же качество, что GigaChat API напрямую.
6. **GigaChat через шлюз изображения не принимает**: загрузка файлов на шлюзе не настроена, `gigachat-2-max`
   ждёт строку, `gigachat-3-pro` и `gigachat3.5` не мультимодальны.

Выборка мала: 10 страниц, в знаменателях вердиктов 4–13 заданий. Разница между тремя лучшими моделями — в
пределах шума; разрыв с GigaChat-2-Max устойчив по всем метрикам распознавания.

## Ограничения

- Модели сторонних поставщиков работают за рубежом: передача им фото тетради ребёнка — трансграничная передача
  данных. Политика `v1` называет получателем только GigaChat API; до смены модели распознавания нужны новая
  версия политики, текст согласия и уведомление Роскомнадзора.
- Промпт распознавания под каждую модель не подбирался — результат сторонних моделей можно улучшить.
- Gemini 3.1 Pro — предварительная версия модели: поведение и доступность на шлюзе могут измениться.

## Как повторить

```bash
CASES=$(ls bench/golden | grep '^ds-' | sed 's/\.json$//' | paste -sd, -)
LLM_GATEWAY_TIMEOUT=75 LLM_GATEWAY_MAX_RETRIES=1 \
  uv run python -m hwcheck bench run --config bench/configs/gw-gemini31pro.json --cases "$CASES"
```

Ответы моделей кэшируются в `.cache/bench/llm`: повторный прогон не тратит бюджет.
