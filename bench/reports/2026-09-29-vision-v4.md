## Что это значит

- **Точность строки и итог проверки — разные вещи.** Flash с `v4` переписал точнее всех, а верных
  вердиктов дал меньше всех. Вердикт зависит от того, разобрала ли вторая модель транскрипцию на задания
  и шаги; основная причина «не уверен» во всех прогонах — шаги решения не разобраны (`steps_unparseable`).
  Следующий рычаг качества — разбор страницы, а не промпт чтения.
- **Рост токенов** у `v4` — более длинные транскрипции: промпт требует переписывать столбики построчно и
  печатный текст учебника целиком.
- **Выборка мала:** 10 страниц, в знаменателях вердиктов 9–13 заданий. Одно задание — 8–10 процентных
  пунктов.

## Как повторить

```bash
CASES=$(ls bench/golden | grep '^ds-' | sed 's/\.json$//' | paste -sd, -)
for c in gw-gemini31pro-v4 gw-claude-opus48-v4 gw-gemini25flash-v4; do
  LLM_GATEWAY_TIMEOUT=75 uv run python -m hwcheck bench run --config bench/configs/$c.json \
    --cases "$CASES" --out .cache/bench/gw/$c.jsonl
done
uv run python -m hwcheck bench report .cache/bench/gw/gw-gemini31pro.jsonl \
  .cache/bench/gw/gw-gemini31pro-v4.jsonl
```
