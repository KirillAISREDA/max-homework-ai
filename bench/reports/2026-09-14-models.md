# Прогон стенда 14.09.2026: модели GigaChat на эталонной разметке

16 кейсов (24 фото, 288 строк эталона), 4 конфигурации, PERS-тариф, строго в 1 поток. ~412 тыс. токенов в пересчёте
на конфигурации (фактически меньше: распознавание 2-Max для 3-Lightning взято из кэша), 224 свежих вызова,
0 ответов 429, 0 сбоев страниц.

## Вывод коротко

1. **Главный источник ложных «ошибок» — распознавание рукописи, а не проверка.** На надёжных кейсах (живые фото
   №52 ×3, альбомы тестеров hw2/hw3/hw4) 2-Max ошибается в 37 из 51 строки-вычисления (CER 20 %):
   «999 + 1 = 1000» → «99 + 1 = 100», «306 − 138» → «206 : 138», «171» → «177». Из-за этого 2 из 4 верных заданий
   альбома hw2 получили «ошибку».
2. **GigaChat-3-Ultra и 3-Pro для распознавания не лучше 2-Max:** те же вердикты на надёжных кейсах, CER строк
   36 % и 27,5 % против 20 %; 3-Ultra медленнее (425 с против 256 с). Распознавание оставляем на 2-Max.
3. **GigaChat-3-Lightning для разбора не годится:** роль страницы верна в 62 % (2-Pro — 96 %), 115 лишних строк;
   его «0 ложных ошибок» — артефакт: страницы учебника приняты за тетрадь, печатное «999 + 1 = 1000»
   сопоставилось с эталоном. Изображения 3-Lightning не принимает вовсе (422). Разбор оставляем на 2-Pro.
4. **Две расшифровки полезны для уточняющих вопросов, но не как единственный сигнал.** На надёжных кейсах
   расхождение 2-Max и 3-Ultra: 19 строк из 51, из них 17 — реальные ошибки распознавания (точность 89 %),
   но это только 46 % всех ошибок — больше половины ошибок у моделей общие. С 3-Pro — полнота 35 %,
   точность 72 %. Вопрос ребёнку по расхождению почти всегда уместен; остальное нужно ловить иначе (строки,
   на которых вердикт «ошибка», — «я прочитал 860 — так?»). Расхождений ~3 на кейс — больше лимита в 2 вопроса,
   нужен отбор по влиянию на вердикт.
5. **Найдена простая причина ложной ошибки в коде:** распознавание пишет два примера из соседних колонок в одну
   строку через широкий пробел, разбор 2-Pro их не разделяет вопреки промпту → строка не проверяется или
   даёт ложное расхождение (№20 hw2). Лечится детерминированным разделением строк по широкому пробелу.
