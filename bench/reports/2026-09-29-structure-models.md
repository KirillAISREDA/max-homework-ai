# Прогон стенда 29.09.2026: модель разбора страницы на задания

Вопрос: можно ли ускорить разбор транскрипции на задания (шаг `vision_structure`, 10 с из 18 с проверки,
25 % стоимости домашки), заменив `gigachat-2-max` быстрой моделью шлюза.

Те же 10 страниц открытого датасета, что и 28.09. Чтение фото — `gemini-3.1-pro-preview` (из кэша
стенда, промпт `v3`), эталон — `gigachat-2-max`. Промпт разбора `vision_structure/v1` писался под
GigaChat и не менялся. Свежие вызовы — только разбор и эталон; потрачено около 40 ₽.

## Вывод

**Модель разбора не менять.** Ни одна быстрая модель не дала итог проверки лучше нынешней. Ближайший
кандидат — GPT-5.4 mini: втрое быстрее за ту же цену, но это новый зарубежный получатель текста заданий
(политика v2 называет только Gemini и GigaChat), а разница на 10 страницах — в пределах шума. Вернуться
к нему, когда стенд вырастет до 30 страниц и политику смотрит юрист.

Ожидание проверки облегчить иначе: промежуточным сообщением ребёнку после чтения страницы.

## Как повторить

Конфигурации — как `bench/configs/gw-gemini31pro.json` с другим `structure_model`; чтение фото берётся
из кэша, если прогон 28.09 уже был.

```bash
CASES=$(ls bench/golden | grep '^ds-' | sed 's/\.json$//' | paste -sd, -)
uv run python -m hwcheck bench run --config <конфигурация> --cases "$CASES"
uv run python -m hwcheck bench report .cache/bench/gw/gw-gemini31pro.jsonl <прогоны>
```
