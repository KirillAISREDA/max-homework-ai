## Подробное описание формата решения

```
«Домашка» — ИИ-помощник для проверки домашних заданий в мессенджере MAX для школьников 1–9 классов и их родителей. Формат — чат-бот MAX (без установки приложений); позже — mini-app MAX для отчётов родителю.

Как работает:
1. Ученик фотографирует тетрадь с решённой домашкой (можно вместе со страницей учебника — до 4 фото в сообщении) и отправляет боту.
2. Бот распознаёт страницы: печатное условие берётся из учебника, решение — из тетради. Распознавание в два этапа: GigaChat переписывает страницу текстом, затем текст раскладывается на задания, шаги решения и ответ.
3. Для каждого задания GigaChat строит эталонное решение, а детерминированный валидатор (SymPy) пересчитывает каждый шаг ученика и сам эталон. Нейросеть не является источником истины по арифметике: ошибку в строке «803 + 169 = 753» находит пересчёт, а не модель. При сомнении бот честно пишет «не уверен», а не ставит ложную «ошибку».
4. Через минуту ученик получает сводку: «№17 — есть ошибка (строка 1)», «№19 — верно» — и кнопку «Разобрать».
5. Разбор ведёт ИИ-тьютор сократическим методом: подсказки трёх уровней (где ошибка → какой приём → полный разбор). Готовый ответ бот не выдаёт до третьего уровня — это закреплено в коде, а не в промпте. Разбор засчитывается, когда ученик сам пишет верное значение (проверка детерминированная).
6. Родитель в своём аккаунте MAX получает итоги — сразу после проверки или сводкой в выбранное время — и не тратит вечер на проверку.

Для родителя и закона: ребёнок подключает родителя ссылкой, проверка открывается после согласия родителя на обработку данных (152-ФЗ); имена детей не собираются, идентификаторы хранятся зашифрованными, фото удаляются через 30 дней, данные — на серверах в России.

Предметы: сейчас математика (арифметика, дроби, уравнения, вычисления столбиком, текстовые задачи). Далее — русский язык (упражнения из учебника): для рукописного текста используется посимвольный OCR без автоисправления — наше исследование показало, что LLM-распознавание «исправляет» ошибки ученика и скрывает 78–80% орфографических ошибок. Затем — остальные предметы 1–9 классов по федеральному учебному плану (выбор предмета и лист ожидания уже спроектированы).

Статус: работающий MVP в MAX с 04.09.2026, прод на сервере в РФ, открытый репозиторий, 303 автотеста, журнал каждого вызова компонента (trace_id, обезличенный пользователь, результат, код ошибки) с отделением тестового трафика.

Частота обращений: одна проверенная домашка — это распознавание (2+ вызова на фото), эталонные решения по каждому заданию, валидатор, классификатор ошибки и 3–10 реплик тьютора — десятки вызовов компонентов на пользователя в день.
```

## Укажите технологический стек

```
- Язык и ядро: Python 3.12, asyncio, pydantic (контракты шагов со схемами), uv, ruff, mypy strict, pytest (303 теста), GitHub Actions CI.
- ИИ: GigaChat API (Сбер) — GigaChat-2-Max: распознавание фото (vision) и эталонные решения; GigaChat-2-Pro: структурирование, классификатор ошибок, тьютор, генератор похожих задач. Промпты — версионированные файлы.
- Детерминированная проверка: SymPy (точная рациональная арифметика, уравнения), собственный безопасный парсер школьной нотации (дроби, смешанные числа, «:», столбики, ответы фразой).
- Распознавание рукописного текста (русский язык, в разработке): ReadingPipeline ai-forever (сегментация + CRNN, ONNX на CPU, без языковой модели).
- Мессенджер: MAX Bot API (long polling; webhook — при росте нагрузки), deep link-приглашения.
- Данные: Redis 8 (состояние диалога, AOF), PostgreSQL 17 (профили, согласия, результаты — в работе), журнал событий JSONL для аналитики и антифрода, фото на диске с TTL 30 дней.
- Инфраструктура: Docker, docker-compose, VPS в России (Москва); целевая — Cloud.ru Evolution (Container Apps → Managed Kubernetes, Managed PostgreSQL/Redis, Object Storage).
- Безопасность и ПДн: TLS с корнем НУЦ Минцифры, шифрование идентификаторов (Fernet), HMAC-обезличивание в логах, согласие родителя с версией политики, удаление данных по запросу.
```
