# Сводка проверки: пункты, номер с точкой, «что дальше». Дизайн

Дата: 2026-09-30. Статус: направление согласовано с Кириллом в чате 30.09 (кусок 3 из 3: проверка →
разбор → сводка), текст ждёт вычитки. Связанные документы:
`2026-09-30-math-misread-guards-design.md`, `2026-09-30-tutor-code-question-design.md`.

## 1. Что случилось

Сводка живой проверки 30.09 — «Проверил! 0 из 2 верно. Задание 2181 — есть ошибка (строка 2) ❌.
Задание 2183 — не смог разобрать решение 🤔». Тестер:

- «указать бы точнее, что ошибка в п. а). Остальное решено верно» — «строка 2» ребёнку ничего не
  говорит, а верные пункты сводка не называет;
- номер «№ 2.181» стал «Задание 2181»: структуризатор отдаёт номер целым числом, код его на странице
  не нашёл;
- «0 из 2 верно», хотя второе задание вовсе не проверено;
- в №2.183 решения нет, только переписанные примеры, а бот пишет «не смог разобрать решение»;
- «как следующую проверку делать?» — после сводки без ошибок бот молчит.

## 2. Решения

| Что | Как |
|---|---|
| Ошибка в задании из пунктов | «№2.181 — есть ошибка в пункте а) ❌ Верно: б), в). Не проверил: г).»; несколько — «есть ошибки в пунктах а), в)» |
| «Не уверен» в задании из пунктов | После причины — те же группы: «Под вопросом: а), б). Верно: в). Не проверил: г).» |
| Ошибка без пунктов | Цитата строки ребёнка: «есть ошибка в строке «700 − 400 = 310»», до 30 знаков |
| Номер с точкой | «№ 2.181» в тетради и «2.177» в начале строки учебника — номер на странице, в сводке «№2.181» |
| Счёт в заголовке | Только задания с вердиктом («верно» или ошибка): «Проверил! 0 из 1 верно.»; без вердиктов — «Проверил!» |
| Только условие | Строки без «=» и с действиями, ответа нет — «вижу только условие, решения пока нет» (причина `no_solution`) |
| Что дальше | Сводка без кнопок «Разобрать» и без вопросов заканчивается строкой «Пришли фото следующего задания — проверю 📸» |

## 3. Дизайн

- `VisionTask.number_label` — номер с точкой («2.181»). Проставляет код по транскрипции
  (`pages.mark_written_numbers`), в JSON-схеме ответа модели его нет (`SkipJsonSchema`). Печатный
  номер учебника переходит к заданию тетради вместе с меткой (`_with_condition`). Номер «№ 2.181»
  больше не читается как «№2».
- Пункты задания — строки с меткой (`reading.line_label`) и строки-действия под ними. Итог пункта:
  есть расхождение — ошибка; есть `misread` — под вопросом; все строки верны — верно; иначе — не
  проверил. Метка встретилась дважды или пунктов меньше двух — прежняя строка без пунктов. Ни один
  пункт не проверен — пункты не перечисляются.
- `no_solution` — в `grade._uncertain_reason` перед `steps_unparseable`: строки только-ответы
  («а) 75») сюда не попадают.
- Уведомление родителю использует `task_label` и получает «№2.181» без изменений.

## 4. Проверка

`tests/test_summary_items.py`: номер с точкой (тетрадь, учебник, десятичные дроби, схема модели),
строка задания по пунктам (одна и несколько ошибок, действия под пунктом, «не уверен»), цитата строки,
только условие и только ответы, заголовок, «что дальше». Прежние тесты сводки обновлены под новый текст.

- Номер с точкой в предметном каркасе (`SubjectTask.number`) — только в сводке математики.
