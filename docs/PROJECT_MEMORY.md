## 1. Продукт в двух абзацах

**«Домашка»** — ИИ-помощник в мессенджере MAX для школьников 1–9 классов. Ребёнок фотографирует тетрадь с
решённой домашкой (можно вместе со страницей учебника) — бот за минуту находит ошибки и **не выдаёт
готовый ответ**, а ведёт к нему подсказками (уровни 0→3, ответ — только на третьем). Родитель получает
итоги и не тратит вечер на проверку.

**Отличие:** арифметику проверяет не нейросеть, а детерминированный пересчёт (SymPy) — LLM не источник
истины; распознавание, объяснение и диалог — GigaChat. Для рукописного русского языка — посимвольный OCR
без «автоисправления» (LLM-vision скрывает 78–80 % орфографических ошибок, см. §6).

- Целевая аудитория: ученики 1–9 классов и их родители. 10–11 классы не берём (другие задачи).
- Сейчас проверяется: математика. Следующий предмет: русский язык (упражнения из учебника).
- Бот: «Домашка ИИ» в MAX. Команда: Кирилл (основатель — продукт, разработка, запуск) + ИИ-агенты
  (Claude Code): разработка по TDD, ревью агентами, PR на каждое изменение.

## 5. Архитектура и инварианты

Целевая архитектура — `docs/architecture.md` (Cloud.ru Evolution, GigaChat API, 1000+ DAU). Сейчас на
пилоте — один контейнер бота + Redis на VPS; переезд в Cloud.ru — когда потребует нагрузка или конкурс.

Инварианты (из `CLAUDE.md`, не нарушать): SymPy — источник истины по математике; FSM диалога управляет код;
ответ раскрывается только на уровне подсказки 3; LLM-шаги — контракт `(input) -> output` со схемой; промпты
версионированы; данные детей минимизированы (152-ФЗ): без ФИО и школы, id MAX не хранится в открытом виде.

Код (`src/hwcheck/`): `llm/` (клиент GigaChat, structured output) · `pipeline/` (normalize, vision, solver,
mathparse, validator, grade, classifier, tutor, generator) · `bot/` (max_api, models, handlers, pages, fsm,
runner) · `events.py` · `photos.py` · `config.py` · `cli.py` (`hwcheck ping | vision | eval | solve | grade |
tutor | generate | bot`).

## 6. Качество: что знаем

- **Vision (математика):** GigaChat-2-Max в одном вызове с JSON отказывает на рукописи; свободная
  транскрипция читает. Печать учебника — почти идеально, рукописные цифры — с ошибками (850→860, «·»→«:»).
  Фото из мессенджера пережаты до 1280 px; апскейл бесполезен (модель сжимает вход сама), кропы не помогли.
- **Validator:** см. §2; не проверяет квадратные уравнения, неравенства, системы, умножение столбиком на
  многозначное, деление уголком. Два нерешённых уравнения подряд с ≥ 2 общими числами — ложная «ошибка».
- **Русский язык (исследование 13.09):** GigaChat vision сохраняет 3 % ошибок ученика, скрывает 78–80 %;
  ReadingPipeline (ai-forever, MIT, CPU/ONNX ~6 с) без языковой модели — сохраняет 66,5 %, скрывает 6 %, но
  искажает 17–24 % верных слов → только «кандидаты» с проверкой, не вердикт.
- **Живые логи:** до исправлений 06–13.09 — 15 проверок, 0 «верно» (ложные ошибки парсера, склейка с чужим
  условием, падения). После PR #12–#15 проверено на альбоме с намеренными ошибками — вердикты верные; **на
  верной работе после выката ещё не проверено**.

## 6а. Рынок, конкуренты, регуляторика (исследование 14.09, источники — в презентации и ответах формы)

- **СберКот в приложении СберKids** (с 01.09.2026) — ближайший конкурент: математика 1–6 класс, фото страницы
  учебника или тетради, наводящие вопросы без готового ответа, подсказки на «правильно ли решил?»; отдельное
  приложение; про родителей и способ проверки арифметики — нет данных (1rnd.ru, 01.09.2026).
- **Готовые ответы:** ГДЗ (gdz.ru ~1,4 млн визитов/мес, SimilarWeb 08.2026), Skysmart «Решения», Алиса AI
  («Умная камера» — ответ с объяснением), Telegram-боты; ChatGPT в РФ без VPN недоступен, DeepSeek доступен.
- **Платформы** (Учи.ру, ЯКласс, Skysmart, Фоксфорд) — свои онлайн-задания или ручная проверка учителем;
  автоматической проверки фото рукописной домашки нет.
- **Рынок:** ~18 млн школьников (2024/25); 62 % школьников 8–15 лет пользуются нейросетями (Анкетолог, 09.2025);
  репетитор 500–2500 ₽/час, семьи тратят 5–6 тыс. ₽/нед (SuperJob, 04.2026).
- **MAX:** 107 млн регистраций (03.2026), > 85 млн в день (05.2026); «Сферум» (журнал, домашние задания) в MAX.
- **Риск 1 — рекомендации Минпросвещения (13.09.2026):** ученикам 1–4 классов самостоятельно пользоваться ИИ
  не рекомендуется; 5–9 — с разрешения учителя; на аттестации — нельзя. Это методические рекомендации, не закон,
  но для 1–4 классов нужен сценарий «под контролем родителя» (см. TODO).
- **Риск 2 — публикация ботов MAX:** по данным Habr (09.2025) публиковать ботов могут только верифицированные
  юрлица РФ, модерация до 48 ч. Проверить, как зарегистрирован «Домашка ИИ» и хватит ли этого для открытого
  привлечения пользователей.
- Стратегия цифровой трансформации образования (2022–2030): ИИ для автоматизации проверки домашних заданий
  (pnp.ru, 01.11.2023).

## 9. Уроки и грабли

- **GigaChat + жёсткий JSON + рукопись = отказ или галлюцинация.** Сначала свободный текст, структура —
  вторым вызовом текстовой модели.
- **PERS-фримиум = 1 поток.** Два параллельных прогона → 429; в боте семафор; eval не запускать параллельно
  с другими вызовами.
- **LLM «исправляет» ученика** — и орфографию (русский), и, вероятно, цифры. Всё, что проверяет ошибки
  ребёнка, должно опираться на детерминированную проверку или посимвольный OCR.
- **Ревью агентами окупается:** в PR #14 и #15 ревью заблокировало 3 сценария ложных «ошибок»/ложного
  «верно», которые тесты пропускали. Каждый PR с логикой проверки — через ревью с запуском злых входов.
- **Живые фото — лучший тест.** Сохранять фото (есть) и смотреть их при каждом спорном вердикте.
- **Прод с пользователями:** перед рестартом — события за 10 минут; код выкатывать `docker compose up -d
  --build bot`, Redis не трогать (13.09 рестарт Redis для проверки уронил загрузку тестера).
- **Логи контейнера пропадают при пересборке** — поэтому `var/bot.log`.
- **Один поллер на токен:** не запускать `hwcheck bot` локально, пока жив контейнер.
- **Windows-окружение:** `TaskStop` фонового `uv run` не убивает дочерний python; heredoc с кавычками в bash
  ломается — правки через скрипты в scratchpad; Clash Verge (TUN, fake-ip) блокирует фреймы claude.ai в Chromium.
- **Хэш id `sha256("hwcheck:"+id)` обратим перебором** — в онбординге переходим на HMAC с секретом.
