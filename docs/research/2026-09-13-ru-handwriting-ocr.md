# Спайк: транскрипция рукописи по русскому языку без «исправления» ошибок ученика

Дата: 2026-09-13 (сессия 12). Цель — решить, чем распознавать текст ученика для проверки
русского языка: главный риск — LLM-vision «исправляет» орфографию, и проверка диктанта
теряет смысл. Скрипты, данные и сырые результаты — во временном каталоге сессии, не в репозитории.

## Выводы

1. **GigaChat-2-Max vision не годится для транскрипции текста ученика** — ни с каким промптом.
   Из 161 проверенной ошибки дословно сохранено 5 (3 %); исправлено на правильное 39–40 %,
   подменено другим словарным словом 38–41 % — **ошибка скрыта в 78–80 %**. Жёсткий промпт
   «буква в букву, сохраняй ошибки» не помог (5 vs 5). Модель галлюцинирует: словарный диктант
   превращается в другой список слов. Кроп половины листа снижает CER, но не отучает «нормализовать».
   Прямая аналогия с инвариантом «LLM — не источник истины по арифметике».
2. **Источник «как написано» — посимвольный OCR без языковой модели.** ReadingPipeline
   (ai-forever, MIT, CPU/ONNX, ~6 с на лист): 66,5 % ошибок сохранены дословно, скрыто 6 %,
   CER 0,12 (у GigaChat 0,30). Char-KenLM вдвое увеличивает скрытые ошибки (6 % → 13 %) при
   небольшом выигрыше в CER — **LM выключать**.
3. **Минус OCR:** 17–24 % правильных слов тоже читаются с искажением → прямой «детектор ошибок»
   даст много ложных срабатываний.
4. **Рекомендуемая архитектура — гибрид:** сегментация + CRNN без LM (текст «как написано») →
   детерминированное выравнивание с **эталонным текстом задания** (учебник/учитель) → расхождения
   — только кандидаты, подаются ребёнку как «проверь слово X» с кропом слова, а не как вердикт.
   GigaChat — на классификацию страницы и печатный текст задания; без эталона «задуманный текст»
   можно брать у GigaChat (его автокоррекция тут полезна) — не проверено.
5. **Сочинение без эталона** — надёжной проверки орфографии ни GigaChat, ни ReadingPipeline не дают.

## Датасет `ai-forever/school_notebooks_RU`

- MIT; 1857 фото (часто 4000×3000, развороты), COCO: `pupil_text`, `pupil_comment`,
  `teacher_comment` — полигоны **слов** с текстом в `attributes.translation`; строка = `group_id`,
  порядок чтения не размечен. test+val — 52 257 слов на 553 листах.
- **Разметка «как написано»** — орфография ученика сохранена (`хвотают`, `ветрина`,
  `кареспондент`, `извесным`); красная правка учителя — отдельными полигонами.
- Шум: зачёркнутое не помечено и входит в текст («Лочадь Лошадь бежит»), вставки над строкой
  непоследовательны, есть опечатки разметчика (`првести` при написанном «провести», `коллекия`).
  Из 200 отобранных ошибок после визуальной сверки по кропам выкинуто 42.
  **Для оценки — годится после выборочной сверки.**

## Методика

- 18 листов val/test (ReadingPipeline учился на train): словарные диктанты, диктанты,
  упражнения/сочинения, 2 листа с плотной правкой учителя. Кроп по полигону листа; в GigaChat —
  через `normalize_image` проекта (≤ 2048 px, JPEG), как в проде.
- Ошибки ученика: кандидаты — слова вне словаря pymorphy3 + вручную найденные «реальные слова»
  (`война`→воина, `едим`→едем); для каждой — правильная форма; визуальная сверка → 158 типов
  (161 вхождение).
- Судьба ошибки — глобальное выравнивание токенов: сохранил / исправил / подменил словарным
  словом / исказил в не-слово / пропустил.
- GigaChat-2-Max, temperature 0,1, строго последовательно: (а) нейтральный промпт «перепиши как
  есть», (б) «буква в букву». 40 вызовов (1 таймаут), 429 не было.

## Результаты (18 листов, 161 ошибка, 1149 прочих слов)

| Система | CER | WER | прочие слова дословно | **ошибка сохранена** | исправлена | подменена словом | не-слово | пропущена | **скрыта** |
|---|---|---|---|---|---|---|---|---|---|
| GigaChat-2-Max (а) нейтральный | 0,301 | 0,53 | 56 % | **3,1 %** | 39,1 % | 41,0 % | 8,1 % | 8,7 % | **80 %** |
| GigaChat-2-Max (б) «буква в букву» | 0,297 | 0,56 | 54 % | **3,1 %** | 40,4 % | 37,9 % | 10,6 % | 8,1 % | **78 %** |
| ReadingPipeline без LM | 0,120 | 0,38 | 76 % | **66,5 %** | 3,1 % | 3,1 % | 26,1 % | 1,2 % | **6 %** |
| ReadingPipeline + char-KenLM | 0,107 | 0,33 | 83 % | 66,5 % | 6,8 % | 6,2 % | 19,3 % | 1,2 % | 13 % |
| RP без LM, лист сжат до 1280 px | 0,118 | 0,39 | 76 % | 64,6 % | 5,0 % | 4,3 % | 25,5 % | 0,6 % | 9 % |

CER — после выравнивания порядка строк (без него у RP 0,176: `LineFinder` путает порядок строк).

Проверка диктанта при известном тексте (флаг, если распознанное ≠ правильной форме): GigaChat —
полнота ~60 %, точность флагов 15–16 %; RP без LM — 97 % / 36 %; RP + LM — 93 % / 44 %
(точность — оценка снизу: сюда входят артефакты порядка строк и листы с правкой учителя).

## ReadingPipeline

- **Лицензии:** MIT — код (`ReadingPipeline`, `OCR-model`, `SEGM-model`) и веса
  (`ai-forever/ReadingPipeline-notebooks`).
- **Состав:** сегментация LinkResNet (ResNet-энкодер, 896×896: полигоны слов и строки) → поворот,
  порядок чтения (`LineFinder`, KMeans) → CRNN (ResNet + BiLSTM + CTC, 64×512, по слову;
  кириллица, латиница, цифры) → опционально char-KenLM 6-грамм в beam search (`ctcdecode`).
- **Зависимости:** detectron2 нет; torch/torchvision (импорт на уровне модулей), opencv,
  onnxruntime, openvino, shapely, pyclipper, scikit-learn, albumentations; `ctcdecode` — только для LM.
- **Веса для CPU/ONNX:** 165 МБ (сегментация 115 + OCR 50) + LM 12 МБ.
- **CPU (i7-11700T, 8 потоков):** без LM 5,7 с на лист, от размера входа почти не зависит.
- На Windows запускается с обходами (заглушка `openvino.runtime`, beam search на Python вместо
  `ctcdecode`, albumentations 1.3.1, `PYTHONUTF8=1`); в Linux/Docker эти проблемы не возникают.
- Наблюдения: OCR читает красную правку учителя поверх написанного (для домашки до проверки не
  критично); порядок строк нужно делать своим.

## `ai-forever/school_notebooks_EN`

Тот же COCO-формат, 90 изображений (70/10/10), ~18,7 тыс. слов, MIT. Содержание — письменные
задания уровня IELTS, не младшая школа; ошибки сохранены (`colomns`, `consumpsion`). Для оценки
английского младших классов не репрезентативен.

## Риски и что не проверено

- Малая выборка: 18 листов, 161 ошибка, один прогон на промпт; разметку ошибок делал один человек.
- Домен: фото датасета 12 МП; реальные фото из MAX (блики, наклон, JPEG, клетка) не проверялись
  (сжатие до 1280 px RP почти не ухудшило).
- Зачёркивания и самоисправления ученика ломают и эталон, и OCR.
- Не проверено: GigaChat на кропах отдельных слов/строк (гибрид «сегментация RP → GigaChat по
  слову»), другие vision-модели, RP на латинице и формулах, порог по уверенности CTC для
  «проверь слово», время RP на CPU VPS, дообучение CRNN на фото из MAX.
