# max-homework-ai

AI-проверка домашней работы в мессенджере [MAX](https://max.ru): ученик фотографирует тетрадь, бот проверяет решения, находит ошибки и ведёт сократический диалог-разбор с подсказками. Родитель получает еженедельный отчёт о прогрессе.

- Инфраструктура: **Cloud.ru Evolution**
- LLM / vision: **GigaChat API** (Max / Pro / Lite)
- Валидация математики: детерминированная (**SymPy**), LLM не является источником истины по арифметике
- Целевая нагрузка: 1000+ DAU × 25+ обращений в день
